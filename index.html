HTML Basics

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It's like the skeleton of a webpage! 🦴

Key Concepts:

  • HTML documents are made up of elements that define the structure of a webpage
  • Elements are represented by tags like <html>, <head>, and <body>
  • Tags usually come in pairs: an opening tag and a closing tag
  • Basic document structure includes DOCTYPE, html, head, and body elements

Basic HTML Document:

<!DOCTYPE html>
<html>
<head>
    <title>My Cute Page</title>
</head>
<body>
    <h1>Welcome to Kawaii Web!</h1>
    <p>This is my first adorable webpage.</p>
    <img src="kitten.jpg" alt="Cute kitten">
</body>
</html>

Common HTML Elements:

  • <h1> to <h6> - Headings (like chapter titles in a book!)
  • <p> - Paragraph (for your text content~)
  • <a href="..."> - Anchor (link to other cute pages)
  • <img src="..."> - Image (show cute pictures!)
  • <ul>, <ol>, <li> - Lists (for organizing items)

CSS Fundamentals

CSS (Cascading Style Sheets) makes your HTML look pretty and cute! It's like the makeup and clothes for your webpage. 💄👗

CSS Syntax:

selector {
    property: value;
    /* This makes things colorful! */
    color: pink;
    background: lavender;
}

Ways to Apply CSS:

  1. Inline styles (using the style attribute right in HTML)
  2. Internal stylesheet (using <style> in head section)
  3. External stylesheet (linking to a .css file - most organized!)

Common CSS Properties:

  • color - Text color (try pink!)
  • background-color - Background color
  • font-family - Font type (use cute fonts!)
  • border - Add borders (dotted borders are adorable!)
  • border-radius - Make rounded corners (so soft!)

Cute CSS Example:

.kawaii-button {
    background-color: #FF9BB3;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 20px;
    font-size: 18px;
    box-shadow: 0 4px 8px rgba(255,155,179,0.3);
    transition: all 0.3s ease;
}

.kawaii-button:hover {
    transform: scale(1.1);
    background-color: #FFD1DC;
}
